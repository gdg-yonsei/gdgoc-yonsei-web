## Baseline verification before any change

- `pnpm lint`: 0 problems. `pnpm test:types`: passed.
- Production browser suite (first run): 156 passed, 3 failed. Debugging is in "Test failures fixed" below.

## Test failures fixed (test-only changes, no app code touched)

- `tests/e2e/home-motion.spec.ts`, "sends a dot along the UI/UX curve while it is hovered": the test hovered before the parts scene armed (sections arm on idle after scrolling). A probe found the scene unarmed at hover time in 6 of 6 loads, and the dot never appeared in 4 of them. The test now waits for `data-motion="js"` on the parts section, as the spotlight test does. Before the fix: 1 failure in 3 runs. After: 8 of 8 passed.
- `tests/e2e/public-flows.spec.ts`, mobile navigation (2 tests): they clicked the menu after `domcontentloaded`, sometimes before React mounted, so the click was lost. Delaying scripts by 1.5s reproduced it every time. The tests now wait for `load`. Before the fix: 1 failure in 8 runs. After: 20 of 20 passed. The same gap affects real users and is finding 2.
- `tests/e2e/home-motion.spec.ts`, "draws the log lane down as the sessions scroll by": failed once in the loaded full run (lane 0.445, needed above 0.524). It did not reproduce in 11 isolated runs, so it is not changed.

## Final verification

Production browser suite after the test fixes: **159 of 159 passed** (9.7 min), including the log lane test. Unit tests, lint and types passed as listed above.

- R-15/R-16: no buzzwords from the R-16 or Empty AI Vocabulary lists in UI copy. "Explore" in meta descriptions is prose, not a CTA. "Connect, learn and grow" is the official GDG motto, so it is brand copy, not a forced rule of three.
- R-24/R-26: every in-page anchor (`#purpose`, `#rights`, `#main` and others) has a matching `id`. `#top` uses the HTML spec's top-of-document fragment. No `href="#"`, empty handlers or `javascript:` links.
- R-32: each `outline: none` has a replacement (`.filter-search:focus-within`, `.log-entry:has(a:focus-visible)`, `.release-card:has(.stretched-link:focus-visible)`, admin input ring). `main` with `tabIndex=-1` is the skip-link target, not a control.
- R-19: `caret-blink` and `pg-ring` loop only while the user hovers or focuses a part module, sit inside `prefers-reduced-motion: no-preference`, and match landing MOTION 3. Skeleton pulses stop under reduced motion.
- R-06: admin `type-eyebrow` tracking is 0.125px, not wide tracking.
- R-17/R-38: dashboard tiles read live counts from `getAdminStats`; no filler names or fake data in placeholders.
- R-27: every public archive has a Suspense fallback or `loading.tsx`, with `error.tsx`, `not-found.tsx` and `global-error.tsx` present.
- Code comments: no banners, end markers, emoji, vague TODOs or three-line comment blocks in application code.

## Follow-up report

The owner approved all four findings, confirmed "UTokyo" as the correct Bridge Hackathon name, and asked for Prettier on every file.

1. **Fixed.** The QR input has a visible label ("Text or URL to encode" / "QR 코드로 만들 텍스트 또는 URL"). The empty preview says what to do, and a too-long value shows an inline `role="alert"` message tied to the input with `aria-invalid` and `aria-describedby`, with no `alert()` and no stale code. The capture hint appears only once a code exists. Measured contrast on the sunken preview: danger text 4.72:1 (light) and 5.30:1 (dark), muted text 5.63:1 and 5.65:1. Test: `tests/components/qr-code-generator.test.tsx` (3 of 4 cases failed before the fix, all 4 pass after).
2. **Fixed.** The menu and close buttons carry `command="show-modal"` / `command="close"` with `commandfor`, so the browser opens and closes the native dialog before scripts run. `onClick` remains for browsers without invoker commands, and a mount effect syncs `aria-expanded` when the menu was opened before hydration. `types/invoker-commands.d.ts` declares the two attributes for TypeScript. Tests: a new browser case holds every script chunk, taps, and expects the menu to open (it failed before the fix), plus a unit case for the attributes.
3. **Fixed.** Hero CTA is now "See sessions" / "세션 보기", matching "See projects" / "프로젝트 보기".
4. **Fixed.** The numbers were dropped from the `qa.mjs` labels; the label text stays.

Also fixed on request: the English Bridge Hackathon kicker now reads "UTokyo" (a landing-copy test checks both languages), and `prettier --write .` was applied, so `prettier --check .` passes for the whole repository.
